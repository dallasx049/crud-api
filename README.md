# CRUD API

# Installation
1. Run npm install
2. Create .env file and populate PORT with value
3. Run the server with one of the commands below
4. Use Postman to test endpoints (http://localhost:PORT/PATH). Example: http://localhost:4000/api/users

# Scripts
- start:dev - run development server 
- start:prod - run production server
- start:multi - run development server with load balancer
